# 宜昌之星 G：可见前冠格架候选

本包是主塔展示候选的有限精修，不是整栋测绘，也不解除原 23 项目具体单栋绑定限制。

依据万豪官网日间外景原图，原 F 的封闭阶梯冠改为可见前缘透空格架，并保留中央不透明遮挡体。只表达可确认的退台、浅金属外框和竖格节奏；格栅数量、杆件截面和结构节点不是实测。

## 继承与未知
- F 全部原对象/网格保留原样，旧主体和旧冠唇隐藏，不与 G 同时导出。
- 展示副本保留 z92 以下原面和材质；冠下锚点 z92、总高105.1及整体包络沿用 F 展示单位，不是米。
- 冠部前缘收分宽度参考新图，未把 F 旧最顶端0.16比例当成实测。未改普通塔身的示意楼层节奏、基座或裙房。
- 中央灰体仅代替照片中不透明遮挡，不指认其为具体设备。背部、冠深、真实侧翼连接仍未知；短侧缘仅作有限前缘转折，未凭空补全完整框架。
- 官网横竖两图相近构图，不能算独立摄影中心；发表/上架时间不是拍摄日期。
- 本版不添加酒店标志、周边附楼、不修正地理朝向，不声称43/51楼层口径已统一。
