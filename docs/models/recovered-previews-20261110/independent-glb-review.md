# 15 项候选原生 → GLB 独立复核

结论：**PASS，15/15 项通过。**

## 方法

先只读重开每份 Blender 原生，从实际 evaluated mesh 顶点建立参考；再由独立 Python 解析器解码 GLB 的二进制 POSITION、索引、节点矩阵与材质引用。未使用导出脚本的几何汇总作为比较输入，未保存或修改任何原生。

核对范围包括默认可见 MESH 白名单、展示台排除、HOLD/未知支承保留、逐对象三角数与材质名称、实际顶点范围、坐标轴转换及原生/GLB 散列。

## 结果

- 15 个源原生 SHA-256 均保持不变，且与前一步 Git / Library 交叉校验一致。
- 对象白名单完全相同，只有明确的 `Display_plinth` / `Presentation_plinth` 被排除。
- 所有 HOLD / 未知支承相关对象保留；未多出雨棚、窗片、左塔等远置研究部件。
- Blender `(X,Y,Z)` 到 glTF `(X,Z,-Y)` 的 Y-up 转换正确。
- 逐对象实际顶点包围盒最大差：0.0000033775 归一单位；检查阈值为 0.0001。
- 每个对象的三角数、材质名称均与独立原生参考一致。
- 没有外部 buffer / 图片 URI，没有图片、相机、灯光、动画或 skin。
