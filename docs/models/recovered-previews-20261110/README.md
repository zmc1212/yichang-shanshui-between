## 网页策略

- 15 项均保持原 business-<sceneId> 标识，搜索、POI、目录和旧地点链接不换身份。
- 新增“模型预览”筛选，16 项包括美联与本轮 15 项；局部候选和身份待核在列表、资料、查看器中分别说明。
- 旧 recovery-pending/registration-pending 链接迁入当前预览筛选并保留所选地点。
- 15 项仅在独立查看器打开后加载；不进入 AUTHORED_MODELS，不替换白膜、不改变街道、相机或地理注册。
- 14 项采用单份压缩后的完整源几何，避免重复下载。光联另有 69,742 三角轻量层与 100,348 三角细节层。
- 新增 16 个唯一网页 GLB，共 5,052,420 bytes（4.82 MiB），单模型按源材质合批为 3–8 个图元；没有图片纹理或外部资源。
- 独立预览三轴等比，以实际几何 bounds 适配视口；单面候选默认查看已建正面；长乐、兴发总部、鑫鼎、共同采用原生资料中已有的局部双面观察方向。静止后按需渲染，关闭释放资源。

## 验证与限制

原生导出、独立 GLB 顶点与材质核对、网页 GLTFLoader/Meshopt 解码、稳定 ID、来源 SHA、全部三角索引与有限顶点检查、原 7 项配准与地图背景保留均有记录。目录导航、搜索别名、定位链接及异步模型加载生命周期检查通过。

本地托管预览的浏览器禁用了 WebGL，属于该环境能力限制；三维视觉与窄屏浏览器检查在正式地址进行，后续结果另见 browser-verification.json。桌面窄屏不等于实体手机性能测试。

## 可复现入口

1. 按 source-manifest.json 的来源标识取回原生，以 SHA256 校验，更新 localPath 为实际目录。
2. 使用 scripts/export-preview-models.py 按 manifest 导出（源文件只读）。
3. 在单独工具目录安装优化脚本注释中的依赖，用 scripts/import-recovered-previews.py 传入 sources、coverage、exports、tools。该步骤不会指定地图落位或补建未知面。
4. 执行 scripts/check-business-models.mjs、check-directory-navigation.mjs、check-scene-location.mjs 及正常站点构建。

源说明与未安装研究构件索引保留在恢复档案中。每一项网页 README 都提供固定来源、模型范围与缺失部分。

实测修复：独立预览 resize 曾累计扩大正交视野，已改为从拟合投影宽高绝对重算；零/单像素瞬态尺寸忽略。操作提示移到画面外，避免遮住模型底部。数值回归见 check-preview-framing.mjs，浏览器截图与逐项资源状态见 browser-verification.json。
