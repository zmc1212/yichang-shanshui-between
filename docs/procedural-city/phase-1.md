# 宜昌程序化城市引擎 · 第一轮（R1）

## 本轮目标

以现有「宜昌 · 江山之间」为底座，建立可逐步接入真实高程数据的地形基础，不覆盖 Sites 原站，不改动 main，不替换现有建筑、道路、地标和 23 项商务楼宇资产。

## 仓库现状核查

- 主分支基线：`649a253053e16de640332a6381b10379eeabdf51`。
- 当前场景已具备真实道路/水域/建筑轮廓、道路分级、道路拓扑、车辆路线约束、局部街道细节及地标模型。
- 当前 `city.json` 覆盖约 15.80 × 14.47 km，包含 16,000 个建筑轮廓部件、3,600 条道路段、64 个水体多边形、100 个绿地多边形。
- README 明确标注当前数据没有 DEM 网格；现有地表着色不能视为真实地形。

## 本轮交付

1. 新增 `src/scene/elevationField.js`：定义本地米制坐标高程栅格契约、输入校验、双线性采样、坡度梯度和 Three.js 地形网格。
2. 对 NoData 采用显式空值处理；不把缺失高程伪造成 0 米，也不跨越缺测像元生成三角面。
3. 垂直夸张仅应用于显示高度，不改写源高程值。
4. 新增 `scripts/check-elevation-field.mjs`，覆盖数据契约、插值、边界、NoData、梯度和几何有效性。

## 真实数据状态

本轮**没有**下载或导入宜昌 DEM，因此没有声称地形已经真实起伏，也没有启用合成山体。当前新增的是经过测试的高程接入与地形网格基础。下一轮应先获取许可清晰、分辨率适用的 DEM（优先核验 Copernicus DEM / ALOS 的宜昌覆盖与垂直基准），统一到项目的局部米制坐标，再在独立数据文件中生成高程瓦片。

## 验收命令

```bash
node scripts/check-elevation-field.mjs
npm run build
```

当前执行环境未在本轮进行完整 npm 安装与浏览器 WebGL 人工验收。真实地形接入前，不应将此模块描述为已经改变现有场景的视觉效果。
