## 交付结果

### 中南冶金街角

以夷陵大道 `way/397144798` 的同侧源路段和现有完整模型包络为边界，新增前场、入口方向连接带与沿街铺装。人行段采用入口投影前 11 / 后 33 展示米的非对称范围，避开胜利一路及周边支路。没有新增模型包络内的入口豁免。

斜向前场与人行道原本会重叠。新模块以连接带、人行道、前场的顺序确定覆盖归属，只裁去已安全地面的交叠部分，不扩大占地。共享边插入相同切点，按中心到边的三角形扇渲染，避免非线性地面高度在 T 接点出现高差。此处理仅用于中南；原五处样板的完整规划数据和渲染顶点保持一致。

建筑侧路缘共形成 5 处开口，其中 2 处因前场与人行道合并而开放；车行道侧路缘完整保留。试验的对称长范围会产生街口另一侧的孤岛，已排除。

旧中南入口观察机位被保留邻楼遮挡；本轮仅将该预设的局部观察方向从 `[0.12,0.08,1]` 提高为 `[0.12,0.5,1]`。原观察目标、源模型、地理锚点、比例和整栋建筑取景计算均未改变。实际 Chrome 中雨棚、裙房及楼前空间已可见。

### 首信—九州补齐段

两处原有人行样板位于沿江大道 `way/39725551` 同侧、同一直线源道路段，中间约 31.149 展示米。新模块直接读取已有铺装横边，生成 3.6 展示米宽的补齐段：11 块铺装、22 段纵向路缘，不增家具。

两端直接使用旧边界坐标，地面高程平滑衔接。实测计算的端点高差为 0；实际渲染的铺装端点及路缘角点 Float32 坐标一致。道路、桥隧、层级、宽度、弯道、障碍或端点条件改变时，整条补齐段停止生成。它独立记为 `street-link`，不计入建筑入口数量。

当前合计 **6 处建筑街道样板 + 1 条连接街段**。沙盘仍为 **7 项建筑模型、16 项独立预览**，本轮没有宣称补齐其他楼宇建模。

## 数据界限与后续

所有铺装、植物和设施都是展示性设计。米数、面积均由现有候选配准与沙盘尺度计算，并非现场测量；真实入口、地界、公共通行条件及设施点位仍待核实。本轮没有加入推测性车道线、人行横道或桥上桥下连接。

下一处适合细化的是宜昌国际广场：先核对模型已有内部街道、开放前场与东侧通道，再接外围地面，避免通用铺装覆盖原模型。其他样板的大范围延伸已经记录不宜直接实施的支路、高架或距离条件，见 `../../iterations/20261110-street-extension-audit.md`。
