### 最终小修正

V39夜景测量发现平面光池的透明双面材质默认绘制两遍。最终源代码给该材质设置Three.js r170已支持的forceSinglePass=true；平面可视结果不变，取消多余背面绘制。上表保留V39真实值，不事后篡改测量；这项小修正随本验收档案一起发布，并单独在最终站点复核。
