## 实机发现后的收尾修正

### 九州雨棚与外侧前场的空隙

V41截图显示，严格避让整个模型AABB会在雨棚至外侧铺装之间留下草地。实际源模型包含前伸构件，导出说明又明确移除了展示性forecourt，因此其完整AABB不等于全部地面均被建筑占据。

V42先增加5片窄接驳带。现场截图仍留断口；进一步核查发现起点误用了入口镜头观察点（GLB坐标[-10.03,3,16.62]），该点在雨棚前方。两级GLB没有绿色地面材质；旧带21个竖向采样均无模型三角形，实际粗网格地面高程约1e-9，远低于铺装0.055。因此根因是连接端点偏离门斗，不能归因为地面遮挡，也不能仅凭“没有穿模”判定视觉连通。

修正后的起点来自原导出报告 `Entry_curved_vestibule_closed_frames`：GLB边界x[-14.73,-11.27]、z[9.06,10.83]，在其前沿稍外取[-13,0.09,10.90]。使用既有归一化、比例、旋转和平移映射到城市，只延伸这条窄带，外侧前场、道路侧连接、模型变换与镜头预设均保持。此门斗本身是PATTERN_INFERRED模型构件；这里确认的是现有模型中的位置，并非现场测绘。

最终接驳带按现有展示比例约4.6米宽、18.99米长，共8片、16个三角面、1152字节，合并在原铺装网格中，不增加绘制调用。独立审查对两级实际GLB分别作369个竖向采样，入口端保留门阶覆盖关系，后续带上没有低处楼体遮挡；高处雨棚完整保留。低地坪仍低于模型最低面0.065，最高铺装约0.055087436，最小模型间隙约0.009912564。

该接驳仅对自己的模型XZ包络采用垂直安全检查；原750个普通轮廓继续完整平面避让，其他楼体、保留源建筑、道路和水体不享有例外。片间及旧前场端连续；地形抬高或保留楼体阻挡时整带拒绝生成。完整证据见 ../../iterations/street-frontages-20261110.json。当前city.json没有terrain栅格，验证使用与场景一致的回退丘陵及其实际地面网格，不把它称为GIS地形验证。

### 所有选中地标的实体轮廓保护

将辅助路名的轮廓避让从自建商务楼扩展到镇江阁等已有实体地标，使用既有模型计算得到的世界包围盒。普通business-poi参考点不生成虚构建筑范围。此项只改变DOM标签位置，不改变地标坐标、模型或相机。V42正式浏览器复查：镇江阁选中时只显示不覆盖阁楼的“西陵一路”，DOM冲突为0，53次绘制、638596三角面，原步道和栏杆完整。江面动态打开时场景active符合原有船只动画，不能误判为按需渲染失效。
