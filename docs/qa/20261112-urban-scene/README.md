## 观察结果

两个GLB楼群、道路与江面同屏；全城总览仍有独立入口。背景楼体可见窗格与屋顶明暗，道路与两侧铺装分色，楼体和行道树投影清楚。白天/夜晚切换、万达全貌加载和返回街区正常；最终返回日景并保留页面。观察到的浏览器控制台无 warning/error 或 shader 编译报错。

最终街区公开canvas统计：23项轻量模型就绪、0个细节模型、135次绘制调用、929,230个渲染三角形；阴影纹素约0.594展示米。以上是该取景一帧的统计，不是帧率保证。新装饰层642段铺装、1,284段路缘、120棵树、80盏灯，最多8个主渲染批次；有界阴影更新复用一张原2048²阴影贴图。

国际广场同期V63前场的新几何gate和新增街面避让gate均通过，分别核验两级GLB内部相交为0，以及恢复区自动让出。原23模型坐标、外形、比例与城市道路、水域数据保留。

## 尚存差距

背景建筑使用通用程序化立面；并非逐栋实景建模。全城仍是正交风格化沙盘，未新增真实DEM、道路标线调查或现场家具数据；这次没有把视频中的全部街区与第一人称功能宣称为已复刻。
