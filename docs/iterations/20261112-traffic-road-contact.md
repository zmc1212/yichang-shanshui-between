# 小车动画与实际道路对齐

用户反馈部分车辆看起来没有在道路上行驶。本轮在原站点、原 23 项模型的基础上修复道路与车流的高程关系。

## 原因与改动

原车流的平面中心线、车道偏移和车头朝向在道路范围内。问题发生在高度：旧道路只在每条源线段的两端取地形高度，长路段内部由三角面插值；小车则每帧独立读取非线性的地形高度。沿江大道两段较长的源线段出现明显高差，路面部分被地形盖住，小车在斜视图中显得偏出道路。此外，车辆原来只跟随平面朝向，没有俯仰与侧倾。

- 地面道路沿原始线段增加高程采样，间隔不超过 25 模型米；平面路段保留原有三角数。源数据中的平面坐标、宽度、分类与层级不变。
- 道路模块提供源路段对应的实际 Float32 渲染三角面。车辆直接从这份几何计算高度，停止独立查询地形。
- 前后、左右接地点共同确定车辆坡度姿态，再检查含车灯的完整足迹，避免车头、车尾或侧边穿入路面。
- 接触查询始终绑定自身源路段，桥下车辆不会吸附到上方桥面。桥梁、隧道、非零层级或无效层级不生成地面车流。
- 查询只检查当前细分段及相邻段。保留 18 条路线、36 辆车、近景显示、30 Hz 动画上限、离屏暂停和端点渐隐回收。

## 验证

- `node scripts/check-road-network.mjs`：10 项，包括真实网格射线与接触查询一致，以及重复、无效、闭合源点索引。
- `node scripts/check-city-traffic.mjs`：7 项，包括源路段边界、单向规则、回收、暂停、图层和资源释放。
- `node scripts/check-traffic-road-contact.mjs`：6 项，以实际车身实例矩阵和独立路面射线检查平地、非线性坡地、纵横坡、窄斜路、结构层级及真实城市完整循环。
- `node scripts/check-scene-environment.mjs`：7 组，真实场景工厂的图层、动效、隐藏、恢复、相机与资源释放行为保持正常。
- 独立审计对 18 条路线、36 辆车的完整循环记录 87,804 个实例矩阵，检查 351,216 个车身底角和 351,216 个含车灯足迹角点：没有离开自身路面、涉水、无效矩阵、无法放置车辆或车身下陷。
- 真实地形三角网复核：原来沿江路面被地形覆盖的 1,098 个采样位置均已消除。

道路网格仍为 5 个；三角数从 119,512 增至 129,846。没有增加车流绘制批次。上述性能记录是几何与行为检查，不代表设备帧率测量。

详见 `docs/qa/20261112-traffic-road-contact/`。数值中的“米”均按场景比例换算，属于模型内距离，不是实测道路高程。
