# 楼宇导览、定位链接与手机查看优化

原站：[宜昌 · 江山之间](https://yichang-miniature-city.gaoronghai.chatgpt.site)。本轮从V21、提交`ca0f198189589594dc5fee7e2db75772cb805f4a`读取并接续。

## 发现的问题与修改

### 连续看楼跟随当前目录

V21在筛选“沙盘模型”后，从九州点击下一处会跳到待恢复的兴发广场。原先前后按钮循环全部30项，忽略了目录的筛选与搜索。本轮统一使用实际分类呈现后的结果顺序，详情显示结果序号与总数，0/1项结果禁用循环；当前地点不在结果中时明确提示，并提供进入结果的路径。

### 搜索与手机目录

增加非输入状态下的`/`搜索快捷键，上下方向键预选结果、Enter打开；Escape先处理搜索或目录。中文组合输入状态不会触发选中。手机目录打开时移交焦点并限制在抽屉内，关闭后恢复到菜单按钮；模态窗口只允许可见、可操作的控件参与Tab循环。关闭地标标签时同时取消其交互，防止透明标签挡住城市。

### 手机介绍面板

把标题、前后导航、关闭、收起/展开及近景入口保留在固定操作区，正文单独滚动。收起介绍不清除当前选择，城市继续显示。面板实际尺寸变化后重新取景；已手动旋转或平移时尊重用户镜头，不自动拉回。

### 定位链接

用稳定地点ID记录楼宇或地标，保留预设视角、日夜模式、目录筛选与搜索。切换地点形成历史记录，同一地点调整视角或搜索替换当前记录；浏览器返回/前进同步恢复。复制的是预设定位链接，不记录用户自由旋转后的任意相机坐标。复制时移除原页面临时查询参数，原站访问权限保持原有设置。无效ID安全回到全景。

### 按需渲染

V21静止时已跳过实际绘制，但仍每帧检查7个模型的细节需求。本轮在镜头、阻尼、自动环绕、江面动态均停止时挂起帧循环；模型加载完成、交互和界面状态改变可重新唤醒。细节选择仅在镜头或模型状态变化后重算。

打开模态窗口或手机目录时，主城市保留画布、镜头和已加载模型，只暂停后台调度。关闭后继续，暂停时间不推进镜头动画。独立候选查看器仍可操作自己的画面。强制保存画面保留可用，自动明信片捕获遵守暂停状态。

## 验证

- 目录语义检查覆盖分类顺序、真实7/1/15筛选、别名、0/1结果边界与中文组合输入标记。
- 定位链接解析检查覆盖当前全部30个稳定ID、中文查询、预设视角、非法ID、输入长度上限和复制链接排除临时查询参数。
- 独立调度检查覆盖事件合并、静止停帧、连续动画、多重暂停原因、恢复补偿、暂停期间失效状态和销毁。
- Hook时序独立复核修复了“同值hash恢复后pending未清，导致下一次选择不再同步URL”的边界。
- 实际浏览器检查将在本轮部署后记录；代码/状态模拟不等同于WebGL、实体手机性能或真实输入法验收。
