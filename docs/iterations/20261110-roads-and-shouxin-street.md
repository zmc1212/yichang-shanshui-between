# 道路分级与首信街道样板

原项目：宜昌 · 江山之间，appgprj_6af0b8d6dbec81919ea6c30c51e88270。
实施基线：最新 V38，提交 e7e85e3812fb99584b940fbbcaee967a597e571c（源码提交以 Git 记录为准）。

## 道路数据

从原湖北数字孪生站只读取源快照38c01bf002511c01294feacd8aa85e54e6342724，对照原文件SHA-256后复现全部3600条道路导出。原points、width、kind、name以及其他city.json字段全部不变。补回highway/osmId/来源宽度3600条、bridge379条、layer392条、lanes368条、oneway1409条。桥属性包括原已标记352条yes和27条未识别viaduct。具体校验见road-source-recovery-20261110.json。源站未改动。

## 道路表达

恢复来源等级后，以主干灰绿、次干暖灰、支路浅米灰区分，桥面接续原highway级别。1081条主干、560条次干、1959条支路使用原宽度。左右路缘分别采样地形，圆弧转角和有限圆端帽避免急弯尖刺；只对共享导出顶点及兼容结构/层级补齐同层汇合，不把平面相交解释为平交。原始OSM节点ID缺失，1123个汇合是导出几何候选，不是实测路口。道路合并为5个静态网格，119512三角面，较当前数据实际生成的旧道路3个网格增加2个网格、76868三角面。

## 首信样板

固定使用已配准首信模型的地理锚点、yaw和等比比例；前场沿既有临江正面推导，连接沿江大道way/39725551的建筑侧人行空间，避开支路way/1451960669。77片无面积重叠的铺装、66段路缘、7组树木/树池、3盏灯、2张长椅；155个完整安全轮廓避让所有道路、水体、模型与保留背景建筑。近门槛铺装低于楼底，沿缓坡接向原道路显示高度，无新增建筑站台。所有设施是展示设计，实际入口、设施位置和精确铺装边界仍待核实。

没有新增推测的车道线、停止线或斑马线。源数据没有lane_markings/crossing；lanes不能证明实际标线。layer不等于桥面高程，本轮没有按层号伪造桥高。

## 交互与成本

现有图层面板新增“街道细节”，关闭后基础路网保留。根据正交投影下道路屏幕宽度决定隐藏/铺装/完整细节，分别进入退出阈值避免缩放抖动；场景外裁剪。重复树木、灯具、长椅实例化，3盏灯的贴地光池合为1网格。新增样板最多12网格、1782三角面、45508字节几何/实例数据；全景0新增样板绘制，街区3次，近景日间11次、夜间12次。实际整场景数据以浏览器前后记录为准。

未修改建筑相机取景算法、默认全貌、幕墙/入口/顶部、聚合、搜索、日夜及模型LOD规则。新细节只在实际请求的一帧前更新，不增加持续RAF；不投射LOD残留的缓存阴影。
