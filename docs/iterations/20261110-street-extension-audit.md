# 沿街连续段核查与首信—九州补齐

日期：2026-11-10。核查基线为原站 V51，源码 `2c2c35ab161ac95ba66662b723e959c2edf491b4`。本记录中的米数来自沙盘的 `0.02 unit/m` 显示坐标，不表示现场实测道路宽度、地界或公共通行权。

## 本轮完成的短段

九州方园与首信的既有样板位于沿江大道同一源路 `way/39725551` 的同侧。两处已生成的人行道之间留有 **31.14913 显示米**的空隙；两端都在该源路第 9 条直线段内，不跨路口、不穿越桥梁，也不延伸到模型内部。本轮新增独立的 `jiuzhou-shouxin-walk`，只补这段空隙。

| 项目 | 结果 |
|---|---|
| 人行铺装宽度 | 3.6 显示米，与两端现有铺装相同 |
| 新增铺装 | 11 个单元 |
| 新增路缘 | 22 段，沿人行道两侧；不在接头加横向封口 |
| 家具、树池、灯具 | 均为 0，复用相邻样板已有街景 |
| 地面新增绘制 | 近景 2 次调用；全景 LOD 关闭后为 0 |
| 几何规模 | 162 个三角形，11,912 字节几何属性与索引 |
| 纹理 | 复用同一个已有铺装纹理，整合到主 renderer 后不新增纹理资源 |

模块保留两端旧人行道横边的原始双精度坐标。新段两侧各有一条纵向路缘，能接到旧路缘。高程在两处原 `groundLift` 函数间平滑插值，两端仍严格使用各自旧函数；未改变旧 5 处样板的几何，也未改变任何模型锚点、比例、朝向或道路源数据。中南新增样板与该段空间分离，不产生干扰。

## 为什么只连接这一段

先读取原 V51 的 planner，在内存中试算 75 / 100 / 150 显示米的半段长度，不修改原配置。核查记录见 `20261110-street-extension-audit.json`。

| 样板 | 核查结果与处理 |
|---|---|
| 首信—九州 | 两个入口投影沿同一路源相差约 136.15m，现有人行道分别覆盖其中 55m 与 50m，只需补约 31.15m；该空隙完整通过障碍核查，因此实施。 |
| 万达 | 现有连续人行道已约 236m。扩大到 300m 的试算在一侧 +126～+144m 出现被拒绝的单元，本轮不继续扩展。 |
| 锦江 | 扩大后的试算在一侧约 -60～-51m 出现中断，附近另有源地图服务道路；不据此补画未经核实的过街连接。 |
| 福江 | 一侧扩大试算出现约 20m 的中断，另一侧接近沿江大道高架源段；不把地面人行铺装直接接上高架或跨过亚栈路。 |
| 中南 | 原通用规则在入口投影约 -11～+34m 区间较连续，继续加长产生数个孤立小块；本轮另用街角裁剪方案处理，不靠加长参数拼出断续步道。 |

其余楼前样板之间主要仍有数百米至数公里距离，且不都位于同一条道路。不能因为名称都叫沿江大道就假定中间连续可通行。

## 实现边界

`src/scene/continuousStreetSites.js` 的 `planContinuousStreetSites` 接收已生成的楼前样板，只读寻找两端铺装。返回独立 link 组与树木避让函数；由主计划放入 `links`，楼前样板继续放在 `sites`。建筑入口连接计数不包含 link，渲染和资源统计包含 link。

生成条件包括：两端存在、同源道路、同侧、同宽、同一直线源段、空隙 1～60 显示米、纵向路缘端点存在。所有完整铺装与路缘多边形还须避让全部保留建筑、完整自建模型包围轮廓、所有道路、水体、旧铺装、旧路缘和街道设施。任一条件不满足，整个补齐段不生成，避免画出局部残段。

## 已完成验证

运行 `node scripts/check-continuous-streets.mjs`，实际输出归档于 `20261110-continuous-streets-check.json`。

- 检查 33 个完整几何占地，全部通过源道路、建筑、水体与旧街景设施检测；既有 6 处楼前计划及所有源数据在调用前后完全一致。
- 两端铺装高程最大差为 **0**；渲染出的端点 X/Y/Z 在 Float32 转换后与旧边界一致。
- 4 个路缘接头的 8 个角点，在 Float32 转换后坐标及顶面高程相同；接头没有横向封口。
- 新段真实渲染的 22 个铺装三角形没有相互覆盖；11 个单元之间逐一共享完全相同的边端点。对原铺装、原路缘和家具亦无正面积覆盖。
- 新路缘至源车行道路面的最小显示余量约 0.60m；附近建筑完整轮廓约 21.17m、水体边界约 79.95m。这是沙盘几何余量，不是现场安全距离。
- 10 项失效条件测试通过，包括缺失端点、换源路、桥梁/隧道/异层、缺路缘、额外水体、额外建筑、额外横街和源路改变为弯道。
- 全景不显示该段；近景为 2 次绘制；关闭街道细节后为 0；稳定状态不请求新帧。

这里的验证覆盖几何、资源和渲染状态，不代替浏览器视觉检查或实体手机性能测试。铺装、材料和接通关系属于展示设计；没有新增未经核实的车道标线、人行横道或真实入口声明。
