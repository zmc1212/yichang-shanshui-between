# 共和 K：原薄棚时相正面中域补齐

恢复原 I 同源全景高清瓦片后，确认薄棚与中横石带、五个普通玻璃湾、第 2/6 深色服务竖带同时存在。K 因此可独立修正原时相，未把 J 厚棚混入。

- 补五个玻璃湾分层、横带与粗框，服务带作深色不透明面及三道浅色分隔，不声称实测百叶片数。
- 原网格世界几何与面材质签名保留；仅旧粗玻璃互斥隐藏，替换件保留修正域外 12 面。塔身、上下檐、薄棚、侧面及总包络保持。
- 新同向正面积共面冲突 0；57 处继承粗玻璃/柱后隐接触单列，非宣称全模型零接触。
- fullGLB 19,632 三角面；实际 light 10,488 面、210,036 字节，detail 19,632 面、251,944 字节。压缩包络最大误差 0.000182 原生单位。
- 原生及独立 fullGLB 回读、实际优化 light CPU 实渲复核。未作浏览器 GPU 验证或实测定位。
- 仅 order22 改版，其余 22 项及 registrations 与 V73 逐项相同。保留道路与车辆并发改动。

## 对上一阶段 J 评估的更正
V73 研究记录曾明确称入口被纵向压扁。整体照片锚点复核不支持这一确定结论；不能据此盲目抬高棚顶。局部照片外围翼部宽度也不等于原模型中央七湾宽度，不能据此盲目缩窄棚宽。J 整体宽度语义及外围映射仍未闭合，继续仅保留候选。

新发现的夜景正视图存在背景及单塔构图疑点，不作为独立实景依据；本次 K 依据为原 I 同源全景瓦片。

原生、fullGLB、脚本、说明及自制对照渲染已备份至 Library；外部照片不入交付包。近期未声称全量模型已经推入 GitHub。
