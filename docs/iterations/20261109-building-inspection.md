# 从建筑全貌进入局部细节

基线：原站 V31 / `abb3800080243b90de45f8ddcc85f6c5bd81ef4f`。用户反馈上一轮近景仍然太远。

## 行为

- “靠近看看”对 7 个已接入自建楼宇进入局部观察，不再要求完整楼体或屋顶 POI 锚点入镜。默认点击 POI 的全貌仍保留。
- 观察位置依据当前网页 GLB 的真实几何确定。幕墙窗口约为源模型高度的 22%，入口为 16%，顶部为 18%；窗口呈正方形，再适应可用屏幕区域。
- 万达选中间 SOHO 塔，国际广场选办公塔。观察位置是模型内的展示点，不是新的地图测绘控制点。
- 局部工具条提供幕墙、入口、顶部、全貌，以及放大/缩小。完整正立面和俯瞰仍保留。
- 局部观察采用屏幕平移，支持沿立面平移；点击当前楼面不会意外返回全貌。选中其他地点的行为保留。
- 进入局部仍按需加载细节；城市、背景楼、道路和地形保留。未更改资产版本、模型比例、朝向或地理位置。
- 入口与顶部的分享链接可恢复视角；旧近景链接继续有效。

## 验证

`check-city-render-lifecycle.mjs` 与 `check-scene-location.mjs` 通过。使用实际场景工厂、相机与 OrbitControls，独立从模型原坐标转换观察点，覆盖全部 7 个模型的桌面与手机两种信息卡状态、3 个局部部位、完整楼体恢复、顶部全貌、背景保留及生命周期回归。

局部检查明确允许整栋建筑超出画面；验收的是局部真实观察点与相邻幕墙区域可见，不再用完整八角点入镜作为局部细节的条件。几何检查不等同于 WebGL 视觉或物理手机性能验证，浏览器结果另行记录。
