# 沿江街区场景视觉改造

## 目标

对照用户提供的 guzhiy 合肥政务区沙盘视频，集中解决实际画面中的三个差距：全城首屏尺度过大、背景楼宇与地面缺少层次、近景阴影过于模糊。保留原宜昌 Site、模型源件和上一轮导览节奏。

## 实现

- 空链接首次打开万达 SOHO—宜昌国际广场沿江街区；新增沿江街区入口，原全城总览仍可返回。取景基于两个完整模型世界包围盒、沿江大道源线段与真实水域采样。约 35° 俯角；16:9 构图约 924 × 520 展示米。
- 既有 GIS 背景楼体增加程序化窗格、层间线、基部阴影和屋顶色阶。楼层比例取源高度，不用展示夸张高度冒充更多楼层；屏幕导数过滤远景细纹。保持原六个背景楼批次，无新增绘制调用。
- 建筑周边地面通过 512² 线性遮罩呈现灰色铺装感，明确排除现有公园、水域，未改变地形或新增土地利用数据。道路改为中灰色路面，所有源线与宽度保留。
- 万达及国际广场附近五条源道路增加有界的窄铺装、路缘、120 棵树和80 盏灯。最多八个绘制批次，使用现有街道与树木图层、LOD、日夜系统。完整避让车行道、水域、源建筑、当前模型和既有街景。
- 复用现有2048²太阳阴影贴图，在近景收紧到可见街区、量化并锁定纹素网格；移动时150ms节流，停止帧提交最后一次更新，不添加帧循环。

## 同期修改保留

开发时远端从 V62 前进到 V63 (7927d406)。先保存本地改动，按原站点源流程同步并无冲突应用。完整保留 V63 的 current23 国际广场前场：以两级 GLB 已核三角面上的新铺装外缘为连接起点，含独立几何审计；未回退成旧模型通道方案。界面与来源说明同时更正旧的“仍关闭”文字。

## 验证

- 楼体模块：当前 16,000 条背景记录参数有限；几何位置、法线、bounds不变；合批及标准材质管线保留。
- 街区构图：24个实际正交投影组合，包含窄屏、宽屏、俯视与变化地高；模型全貌和环境点保留边距。
- 阴影：430个实际矩阵接收面/遮挡物投影，覆盖街区、立面、板边、日落与生命周期。
- 道路：原8项源宽度、层级、交叉与预算检查。
- 导览：原18项控制器与3路线12站检查，继续默认5秒，可选3/5/8秒，单站模型等待最多3秒。
- 定位：原链接解析与浏览器历史hook检查。
- 实际scene factory：环境、隐藏/遮罩、交通、静止睡眠、释放，以及新街区入口、俯视、图层、全景重置。CPU检查不冒充GPU视觉验收。

## 精度说明

材质、树种和设施为展示设计，不是实测立面或铺装。23项当前模型与原落位数据保留，16项近似落位范围说明继续适用；没有DEM，不把风格化山体标为真实地形。
